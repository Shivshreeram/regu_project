TROUBLESHOOTING QUICK FIXES
================================================================================

Problem: CUDA out of memory
→ Reduce batch_size in config.yaml (16→8)

Problem: "File not found" errors
→ Run python verify_implementation.py to check setup

Problem: Poor translation quality (BLEU <20)
→ Check that all CSV files exist in same directory
→ Increase num_epochs in config.yaml (5→8)  
→ Verify LoRA rank is 64 (not 16)

Problem: Glossary file missing
→ Ensure build_glossary.py ran successfully
→ Check pharma_glossary.json was created

Problem: Training interrupted?
→ Re-run python train_improved.py (continues from checkpoint)

Problem: Need to process different document?
→ python process_document_improved.py path/to/your/document.docx

For more help:
→ Read README_NEW.md
→ Check IMPLEMENTATION_SUMMARY.md
→ Review QUICKSTART.py
